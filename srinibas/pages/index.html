📁 File-Based Routing

Drop files into pages/ and they become routes. API handlers go in pages/api/.

pages/index.html → / pages/about.html → /about pages/api/hello.mjs → /api/hello

🔒 Session Auth & Security

Scrypt password hashing, 32-byte session cookies, CSRF protection, host & path sanitisation.

Set-Cookie: launcher_session=... HttpOnly; SameSite=Lax; Path=/

🪣 Token-Bucket Rate Limiter

Per-user, per-key, per-service rate limiting with HTTP 429 & Retry-After headers.

HTTP/1.1 429 Too Many Requests Retry-After: 3 X-RateLimit-Remaining: 0
