About This Project

A Next.js-style runtime built from scratch with zero npm packages.

🎯 What Is This?

This project recreates the core developer experience of Next.js using only native Node.js APIs and standard web technologies. There are no npm packages installed — no React, no Webpack, no Express, no third-party libraries at all.

Features include file-based page routing (pages/), API route handlers (pages/api/), server-side rendering with getServerSideProps, static asset serving (public/), native scrypt authentication, and a token-bucket rate limiter.

📁 Project Structure
